# VetFlu 🦆 — окна риска заноса ВПГП

Предиктивная витрина экосистемы [VetInSilico](https://shray77.github.io/): **в какие недели года и на каких миграционных путях (флайвеях) транзит диких водоплавающих птиц создаёт условия для заноса высокопатогенного гриппа птиц (ВПГП, H5 HPAI) в регионы РФ.**

Живая витрина: https://shray77.github.io/vetflu-site/

## Модель (фазы 1–3: миграция + погода + фон вспышек)

Итоговый индекс **R (0–100)** по каждому из 4 флайвеев, покрывающих территорию России:

| Флайвей | Цвет | География |
|---|---|---|
| Восточно-Атлантический | синий | Балтика, Северо-Запад, Беломорье, Мурман |
| Черноморско-Средиземноморский | оранжевый | Крым, Кубань, Ростов, Маныч, Каспий |
| Центральноазиатский | фиолетовый | Ю. Урал, Зауралье, З. Сибирь, Кулунда, Тыва |
| Восточноазиатско-Австралазийский | зелёный | Забайкалье, Байкал, Амур, Приморье, Камчатка |

M = нормированный взвешенный вклад 8 групп видов-резервуаров (кулики, речные/нырковые утки, гуси, лебеди, лысуха, чайки, казарки). У каждой группы — осеннее и весеннее окно пролёта (ISO-недели), пик и размах (гауссиана); осень считается полным весом, весна ослаблена (0.62), плюс фоновый уровень резидентных птиц. Пики сдвинуты по флайвеям: юг проходит осенью позже (2 недели), весной раньше.

**Погодный слой (фаза 2):** R = M × MW × MB, где MW = 0.70 + 0.45·W + 0.25·P (±40%/−30% к миграционной базе):
- **W — форсаж движений** = 0.6·A + 0.4·F: A — аномалия холода (средняя за 7 дней против нормы той же даты 2015–2024, −8°C → максимум), F — доля суток с Tmin<0 за 14 дней (прошедшие + прогнозные; прокси ледостава и концентрации на полыньях);
- **P — персистентность** = clamp(1 − (T+5)/40): H5N1 в холодной воде живёт недели, в тёплой — дни.

Погода — **Open-Meteo** (та же безключевая API, что под капотом vet-meteo): архив 2015–2024 для норм (кэш навсегда) + прогноз past7/next7, 4 точки на флайвей (16 городов РФ).

**Фон заносов (фаза 3):** MB = 0.85 + 0.30·B (±15%). B — свежие события ВПГП в коридоре флайвея из **WOAH WAHIS** (публичный POST-API `wahis.woah.org/api/v1/pi/event/filtered-list` — тот же источник, что скрейпит [ВетКарта](https://shray77.github.io/vet-heatmap/)): окно 60 дней, вес события по свежести последнего рапорта (≤14 дн — 1.0, ≤30 — 0.6, ≤60 — 0.3), страны коридора — полный вес, смежные — 0.4, сатурация на 10 условных единицах. Коридоры заданы в `scripts/fetch_outbreaks.mjs` (CORRIDORS). Если WAHIS недоступен — B нейтрален (MB = 1.00), витрина деградирует до миграционно-погодного индекса.

Пересчёт — **GitHub Actions ежедневно в 06:00 МСК** (`.github/workflows/update.yml`): погода + вспышки + сборка модели, результат коммитится в data/. Скрипты деградируют аккуратно: нет прогноза — витрина показывает миграционную базу M; нет вспышек — B нейтрален.

**Бэктест:** ретроспективный прогон календаря M по неделям волн 2020–2023 встроен в model.json (`backtest`) и витрину («Проверка глазами»): осенние волны 2020/2021/2022/2023 попадают в окна M≥45, летняя каспийская волна 2021 — честный промах (гнездовые колонии, не транзит — зафиксированное ограничение модели).

Параметризация — экспертная, по открытым орнитологическим сводкам (флайвеи BirdLife/Wetlands International, региональные фенокалендари). План уточнения: недельная абундантность **eBird Status & Trends** (R-пакет `ebirdst`) и GPS-треки **Movebank**.

## Дорожная карта

- **Фаза 1 (готова):** календарь пролёта + индекс M. Витрина: Leaflet-карта коридоров с узлами концентраций, скраббер недель 1–52, календарная полоса, справочник видов, методология и историческая сверка с волнами 2020–2023.
- **Фаза 2 (готова):** множители W и P — живая погода Open-Meteo (аномалии холода против норм 2015–2024, ледостав, персистентность), 16 точек × 4 флайвея, ежедневный Actions-пересчёт с коммитом в Pages.
- **Фаза 3 (готова):** множитель фона заносов **B** из WOAH WAHIS (живой публичный API), бэктест по волнам 2020–2023 (таблица «Проверка глазами» + `backtest` в model.json), публикация индекса с полным разложением в JSON для сервисов экосистемы.
- **Дальше:** уточнение календаря по eBird Status & Trends / Movebank, калибровка коэффициентов по ретроспективе, RSS-лента окон риска.

## Структура

```
index.html              — витрина (тёмная тема экосистемы, Leaflet из vendor/)
data/migration.json     — экспертная параметризация: группы видов × флайвеи
data/points.json        — 16 метеоточек (4 на флайвей) для погодного слоя
data/climate_cache.json — кэш климатических норм 2015–2024 (Open-Meteo archive)
data/weather.json       — текущие W/P по флайвеям (пишет Actions или scripts/fetch_weather.mjs)
data/outbreaks_live.json — свежие HPAI-события WAHIS + B/MB по флайвеям (пишет Actions)
data/model.json         — результат расчёта: 52 недели × 4 флайвея (M, R, фаза, сезон, топ-вклады) + backtest
scripts/fetch_weather.mjs — нормы (кэш) + текущая погода → data/weather.json
scripts/fetch_outbreaks.mjs — WOAH WAHIS → фильтр ВПГП → коридоры → B/MB → data/outbreaks_live.json
scripts/build_model.mjs   — пересчёт модели → data/model.json
.github/workflows/update.yml — ежедневный пересчёт в 06:00 МСК
terms.html              — условия использования и дисклеймер (ред. 2, общий юр-слой VetInSilico)
vendor/                 — Leaflet локально (без CDN, открывается из РФ)
```

## Дисклеймер

Информационный сервис, «как есть», **не** ветеринарный совет и **не** система раннего предупреждения в нормативном смысле. Индекс упрощён и не заменяет эпизоотический мониторинг; погодные данные — модельные выходы Open-Meteo, а не официальный гидрометеорологический прогноз; данные вспышек (WOAH WAHIS) отстают от реальных событий и не заменяют официальные каналы Россельхознадзора (ФСВПС). При подозрении на грипп птиц обращайтесь в государственную ветеринарную службу вашего региона. Подробности — [terms.html](./terms.html).
