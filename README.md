# VetFlu 🦆 — окна риска заноса ВПГП

Предиктивная витрина экосистемы [VetInSilico](https://shray77.github.io/): **в какие недели года, на каких миграционных путях (флайвеях) и по каким каналам создаются условия для заноса высокопатогенного гриппа птиц (ВПГП, H5 HPAI) в регионы РФ.**

Живая витрина: https://shray77.github.io/vetflu-site/

## Модель v2.0 «каналы риска» (фазы 1–3 + каналы)

Итоговый индекс **R (0–100)** по каждому из 4 флайвеев, покрывающих территорию России:

**R = max(M, C, Z) × MW × MB** — берётся максимум из трёх каналов риска, умноженный на живые множители (погода × фон вспышек). `chan` — канал-победитель (argmax).

| Флайвей | Цвет | География |
|---|---|---|
| Восточно-Атлантический | синий | Балтика, Северо-Запад, Беломорье, Мурман |
| Черноморско-Средиземноморский | оранжевый | Крым, Кубань, Ростов, Маныч, Каспий |
| Центральноазиатский | фиолетовый | Ю. Урал, Зауралье, З. Сибирь, Кулунда, Тыва |
| Восточноазиатско-Австралазийский | зелёный | Забайкалье, Байкал, Амур, Приморье, Камчатка |

### Каналы риска (шкала 0–100, статика на всю неделю года)

- **M — транзит**: миграционный календарь 8 групп видов-резервуаров (кулики, речные/нырковые утки, гуси, лебеди, лысуха, чайки, казарки). У каждой группы — осеннее и весеннее окно пролёта (ISO-недели), пик и размах (гауссиана); осень — полный вес, весна ослаблена (0.62), плюс фоновый уровень резидентных птиц. Пики сдвинуты по флайвеям: юг проходит осенью позже (2 недели), весной раньше.
- **C — колониальный** (`C_fw(w) = 100·c_fw·gauss(w, peak=28, σ)`): гнездовые скопления чайковых, бакланов, пеликанов, лысух — активен июнь–август, форму задаёт гауссиана с пиком на неделе 28. Параметры (c · σ): Черном. 0.82·4.5, В-Атл 0.62·5.0, В-Азия 0.55·5.0, Центр-Аз 0.42·5.0. **Честно:** канал добавлен пост-хоком после разбора промаха v1 по летней каспийской волне 2021 — его попадание в бэктесте по этой волне не является независимым подтверждением.
- **Z — зимовочный** (`Z_fw(w) = 100·z_fw·trap(w)`): массовые зимовки водоплавающих — трапеция с заворотом через Новый год (дуги окружности недель 1–52, helper `arcContains`/`arcDist`): подъём start→full1, плато 1.0 full1→full2, спад full2→end. Параметры (z; start→full1→full2→end): Черном. 0.88; 44→50→5→10 (Каспий-Азов-Черноморье, ноябрь 2022 Дагестан), В-Атл 0.50; 45→51→4→9 (Балтика, полыньи Северо-Запада), В-Азия 0.38; 46→51→3→9 (юг ДВ: Ханка, Приамурье), Центр-Аз 0.25; 46→50→3→8 (юг ЗапСибири).

На текущей неделе с живыми данными каждый канал умножается на MW×MB: `R_ch = clamp(ch × mw × mb, 0, 100)`, `R = round(max(R_M, R_C, R_Z))`; флаг `sat = true`, если сырой максимум до клампа превысил 100.

### Живые множители

- **MW = 0.70 + 0.45·W + 0.25·P** (±40%/−30% к канальной базе) — погода **Open-Meteo** (та же безключевая API, что под капотом [vet-meteo](https://shray77.github.io/vet-meteo/)): архив 2015–2024 для норм (кэш навсегда) + прогноз past7/next7, 16 точек. **W — форсаж движений** = (0.6·A + 0.4·F) × **сезонные ворота v2.6**: A — аномалия холода (−8°C → максимум), F — доля суток с Tmin<0 за 14 дней (прокси ледостава и полыней); ворота wSeasonGate(неделя) — сентябрь–апрель полный вес, лето 0.5, плечи в мае/конце августа — холод концентрирует птиц на незамерзающих участках только в холодный сезон (Opata et al. 2025, SHAP: топ-предиктор — минимальная температура именно осенью; июльская аномалия холода при линьке и рассредоточении больше не даёт полного форсажа); **P — персистентность** = clamp(1 − (T+5)/40): H5N1 в холодной воде живёт недели — действует круглогодично.
- **WD с v2.5 — траекторный ветровой канал (упрощённый HYSPLIT)**: для каждого из 16 узлов восстанавливается **обратная кинематическая траектория** воздушной массы за 96 ч (шаг 6 ч) по приземному ветру **Open-Meteo** (локальная сетка 3×3 ±4°, билинейная интерполяция, кламп к краю — осознанное упрощение; `scripts/fetch_trajectories.mjs`, без бинарника NOAA). Траектория сопоставляется с активными очагами WAHIS (≤21 дн, опорные точки стран из `country_coords.json` — координат WAHIS не отдаёт): `w_raw = Σ recency(≤14 дн = 1.0, ≤21 дн = 0.7) × exp(−d_min/300 км)`, где `d_min` — мин. дистанция трека до очага. `WD_узла = 1.00 + 0.15·(1 − exp(−w_raw/2))`, `WD_флайвея = Σ share·WD_узла` (доли транзитного потока). Треки публикуются в `model.json → wind_traj.per_node` (16×17 точек) — можно проверить глазами. Фолбэк: нет свежего `wind_traj.json` (≤2 дней) → секторная эвристика v2.2 (`fetch_wind.mjs`, 72 ч у границы). **Честно:** однослоевая кинематика по ветру 10 м — не полный HYSPLIT (без вертикальных скоростей и вымывания осадками); для индексного множителя ±15% точность достаточна.
- **MB = 0.85 + 0.30·B** (±15%) — фон заносов: свежие события ВПГП в коридоре флайвея из **WOAH WAHIS** (публичный POST-API `wahis.woah.org/api/v1/pi/event/filtered-list` — тот же источник, что скрейпит [ВетКарта](https://shray77.github.io/vet-heatmap/)): окно 60 дней, вес по свежести рапорта (≤14 дн — 1.0, ≤30 — 0.6, ≤60 — 0.3), страны коридора — полный вес, смежные — 0.4, сатурация на 10. **С v2.3 — дистанционная модель (И1)**: координаты страны (опорные точки, `data/country_coords.json`) → гаверсинус-дистанция до каждого из 16 узлов → exp(−d/1000 км); у каждого узла свой B/MB (`geo.per_node`); FAO EMPRES-i API недоступен (HTTP 404, 2026-10-12) — остаёмся на WAHIS.

- **M с v2.3 — бленд с eBird S&T (И2)**: транзитный канал смешан с недельными кривыми относительной абундантности (α = `model.ebird_alpha` = 0.3, `data/ebird_phenology.json`, генерация `scripts/build_ebird_phenology.mjs`). Бэктест 5/5 сохранён.
- **HG с v2.4 — гео-фактор среды обитания (И8)**: `HG = clamp(0.92 + 0.20·gh, 0.92, 1.12)`, где `gh = 0.40·вода_n + 0.30·NDVI_n(неделя) + 0.30·птица_n` — статические драйверы из **Opata et al. 2025** (Sci Rep, [s41598-025-04624-x](https://www.nature.com/articles/s41598-025-04624-x): поверхность воды, NDVI и плотность птицеводства — в числе главных переменных ML-модели наступления ВПГП в Европе, 94%/88% честный OOS). Источники: вода — **JRC Global Surface Water v1.5** occurrence 1984–2024 (средний % воды в окне ±0.02° ≈ 4.4 км), NDVI — **MODIS MOD13Q1** (250 м, 16 дн), месячная климатология 2023–2025 через ORNL DAAC Web Service, плотность — **FAO GLW-4** 2015 (chickens+ducks, голов/км², Harvard Dataverse). Данные — `data/habitat.json` (генератор `scripts/build_habitat.py`: GSW-тайлы через /vsicurl Range-запросы без полной скачки; запускается вручную — климатологии стабильны). Сатурационные нормировки: вода `1−exp(−%/25)`, NDVI `1−exp(−NDVI/3500)`, птица `1−exp(−D/2000)`. Считается пер-флайвей (среднее по хабам) и пер-узел (свой NDVI/вода/птица, фолбэк на флайвей). Фактор — модуляция: каналы, бэктест и пороги не тронуты.
  **Честно о переносе (v2.6, «оно на европе»)**: статья обучала XGBoost+SHAP на вспышках Европы (NUTS3, 2006–2021), её веса в явном виде не переносятся — мы берём только ранжирование категорий драйверов (среда > биоклимат > плотность птицеводства, что и отражено в сплите 0.70/0.30) и сезонность температуры (→ ворота W v2.6). Перенос на РФ не валидирован независимой выборкой — поэтому HG жёстко ограничен диапазоном 0.92–1.12: даже полная ошибка переноса сдвигает R не более ±10%. Плотность птицы — GLW-4 2015 (последний открытый глобальный растр; российские агрохолдинги в нём есть, но возраст данных — осознанное ограничение).

Graceful degradation: нет свежей погоды — R = max(M, C, Z) без живых множителей; нет WAHIS — MB = 1.00; нет `habitat.json` — HG = 1.00. Каналы всегда работают на статике.

### Узловая детализация (16 узлов)

Каждый флайвей несёт 4 узловые точки (`data/points.json`) с экспертной долей транзитного потока **share** (Σ по флайвею = 1) и флажками **colony**/**wintering** (Мурманск, Архангельск, Астрахань, Магадан — колонии; Астрахань, Краснодар, Ростов, Калининград, СПб, Хабаровск, Благовещенск — зимовки). Погодный множитель считается **по узлу** из тех же данных weather.json (без повторных запросов): A = clamp(−anomaly/8), F = frost14, W = 0.6A+0.4F, P = clamp(1−(obs7+5)/40), MW_узла = 0.70+0.45W+0.25P; `R_узла = round(clamp(chan_value × MW_узла × MB × BP × WD × HG_узла, 0, 100))` (v2.3: MB пер-узла — гаверсинус; v2.4: HG пер-узла, фолбэк на флайвей) — публикуется в `nodes` model.json, таблица «Узлы сейчас» и маркеры карты ∝ R.

### История R, бэктест, RSS

- **История**: `build_model.mjs` ежедневно дописывает в `data/history.json` запись `{date, per_flyway: {ea:{m,c,z,mw,mb,r,chan},…}}` (дедуп по дате, кап 180); в model.json вкладываются последние 90 дней (`history`) — по ним рисуются спарклайны на карточках флайвеев.
- **Бэктест v2**: по волнам 2020–2023 на их неделях считаются все три канала, `hit = max(M,C,Z) ≥ 45`. Осенние волны 2020/2021/2022/2023 — транзит ✓; летняя каспийская 2021 (н27, M=4) — колонии C≈80 ✓ (пост-хок, см. выше). Публикуется в `backtest` model.json и витрине с колонкой «Канал».
- **RSS**: `feed.xml` (RSS 2.0, ru, в корне репо) — смены фазы риска (ph_r) любого флайвея между соседними днями истории + стартовое состояние, последние 20 событий.

Пересчёт — **GitHub Actions ежедневно в 06:00 МСК** (`.github/workflows/update.yml`): погода + вспышки + модель + OG-картинка, результат коммитится в data/. Параметризация — экспертная, по открытым орнитологическим сводкам; план уточнения — **eBird Status & Trends** и **Movebank**.

## Витрина и API

- Карта коридоров (Leaflet из vendor/, без CDN) + 16 узловых маркеров (размер/цвет ∝ R узла), скраббер 52 недель с ведущим каналом недели, календарная полоса, карточки флайвеев с бейджем канала, мини-барами M/C/Z и спарклайном истории, «Узлы сейчас», «Прогноз сезона» (w+1…w+4), бэктест, методология с мини-FAQ, API-секция.
- **model.json** — главный документ: `series` (52 недели × {m,c,z,chan,…}), `nodes`, `history`, `backtest`, `weather`, `outbreaks`, `channels` (параметры каналов). Примеры:
  ```bash
  curl -s https://shray77.github.io/vetflu-site/data/model.json | jq '.series.ea.weeks[] | select(.r != null)'
  curl -s https://shray77.github.io/vetflu-site/data/model.json | jq '.nodes'
  curl -s https://shray77.github.io/vetflu-site/feed.xml
  ```
  GitHub Pages отдаёт `Access-Control-Allow-Origin: *` — можно фетчить из любого клиента без ключей.
- **feed.xml** — RSS-лента смен фазы риска; **og-image.png** — OG-картинка (генерит `scripts/make_og.py`, PIL).

```

scripts/build_habitat.py  — генератор data/habitat.json: JRC GSW v1.5 (/vsicurl) + MOD13Q1 (ORNL) + GLW-4 (Dataverse); вручную, не в CI
scripts/build_model.mjs   — каналы M/C/Z, узлы, история, бэктест v2, model.json + feed.xml

terms.html              — условия использования и дисклеймер (ред. 2, общий юр-слой VetInSilico)

```

## Дисклеймер

Информационный сервис, «как есть», **не** ветеринарный совет и **не** система раннего предупреждения в нормативном смысле. Индекс упрощён и не заменяет эпизоотический мониторинг; погодные данные — модельные выходы Open-Meteo, а не официальный гидрометеорологический прогноз; данные вспышек (WOAH WAHIS) отстают от реальных событий и не заменяют официальные каналы Россельхознадзора (ФСВПС); колониальный канал — пост-хок и ждёт независимой проверки. При подозрении на грипп птиц обращайтесь в государственную ветеринарную службу вашего региона. Подробности — [terms.html](./terms.html).
